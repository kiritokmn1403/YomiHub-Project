Usage

Extension sources can be downloaded, installed, and uninstalled via the main Tachiyomi app.
They are installed and uninstalled like regular apps, in .apk format.

Add the Repository

If the button doesn't work, add the repo manually using this link:
https://observeroftime.frama.io/tachiyomi-extensions/index.min.json

Downloads

Alternatively, you can download the .apk you want from here and install it manually.
