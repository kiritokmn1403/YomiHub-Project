Why the Tachiyomi Extension Repo Is Now Required

Tachiyomi originally shipped with extensions pre-bundled inside the app. That changed in January 2024 when DMCA takedown notices from publishers forced the project to remove all built-in extension support. The result is that every fresh Tachiyomi install now opens with a completely empty Browse tab, no sources, no extensions, just blank.

The extension repo system was designed as the solution. Instead of bundling extensions, Tachiyomi connects to external repository URLs where the community hosts and maintains extension files. You paste in a repo URL once, and the app pulls the full extension catalog from that source automatically.

Important: The original Tachiyomi.org extension repository no longer works. Any old repo URL ending in tachiyomi.org will fail. The Keiyoushi URL above is the correct replacement in 2026.

How to Add the Tachiyomi Extension Repo – Step by Step

The process takes under two minutes from start to first extension installed. Follow each step in order and the Extensions tab will go from completely empty to a full catalog.

  1. Open Tachiyomi and tap More in the bottom right corner of the screen, then tap Settings.
  2. Tap Browse, then tap Extension Repos. If you see any old URLs listed here, delete them first. Outdated repo URLs from 2023 or earlier will not work.
  3. Tap the plus icon (+) in the top right to add a new repository. A text field will appear.
  4. Paste the Keiyoushi URL exactly as shown above. Even a single missing character will cause the add step to fail. Tap Add to confirm.
    https://raw.githubusercontent.com/keiyoushi/extensions/repo/index.min.json
  5. Go back to Browse → Extensions and tap the refresh icon in the top right corner. Wait 20 to 30 seconds for the full Keiyoushi catalog to load.
  6. Search for the source you want, tap the download icon to install it, then tap the shield icon to Trust the extension. Extensions will not load any content until they are trusted.
Extension Repos screen with the Keiyoushi URL confirmed – the catalog will now load in the Extensions tab

Tip: After adding the repo, always restart Tachiyomi completely before searching for extensions. Some devices do not refresh the catalog until the app is fully closed and reopened.

What If the Repo Still Fails?

If the Keiyoushi URL fails repeatedly, there are two alternative approaches. First, visit keiyoushi.github.io directly in your browser and tap the “Add to Tachiyomi” button. This uses the automatic install method instead of manual URL paste. Second, if you are in a region with restricted GitHub access, connecting to a VPN before adding the repo usually resolves connection timeouts.

Frequently Asked Questions

What is the Tachiyomi extension repo URL?

The official and most trusted Tachiyomi extension repo URL in 2026 is the Keiyoushi repository: https://raw.githubusercontent.com/keiyoushi/extensions/repo/index.min.json. Add this in Settings → Browse → Extension Repos to unlock the full extension catalog.

Why did my Tachiyomi extension repo stop working?

The original Tachiyomi extension repository was taken down in early 2024 following DMCA notices from publishers. Any old URL ending in tachiyomi.org no longer works. The community replacement is Keiyoushi, which is actively maintained and hosts 100+ manga sources.

Is the Keiyoushi repo safe?

Yes. Keiyoushi is the most widely trusted community-maintained extension repository for Tachiyomi and Mihon. It is fully open source, hosted on GitHub, peer-reviewed by the community, and used by millions of readers worldwide. The source code for every extension is publicly readable.

Can I use the same repo for Mihon?

Yes. The Keiyoushi extension repo URL works identically in Mihon, Aniyomi, TachiyomiJ2K, TachiyomiSY, and all other forks. The exact same URL and the exact same steps apply to every Tachiyomi-based app.

How many repos can I add to Tachiyomi?

You can add multiple repositories. However, most users only need Keiyoushi. Adding too many repos can cause extension conflicts, duplicate sources appearing in the list, and slower catalog updates. Only add Yuzono or Kavita if you specifically need a source they offer that Keiyoushi does not.

What is tachiyomi extensions revived?

Tachiyomi extensions revived refers to the Keiyoushi project, which rebuilt the entire extension ecosystem after the original Tachiyomi repository was shut down in 2024. Every major source, including MangaDex, Toonily, Batoto, Mangakakalot and more, was ported to the new system by volunteer developers.

Where can I find Tachiyomi extensions on GitHub?

Tachiyomi extensions on GitHub are hosted at github.com/keiyoushi/extensions. This is the official source for all community-maintained extensions compatible with Tachiyomi, Mihon, and their forks.

How do I fix failed to fetch available extensions Tachiyomi?

This error means no valid repository is connected. Go to Settings → Browse → Extension Repos, delete any old URLs shown, and add the Keiyoushi URL: https://raw.githubusercontent.com/keiyoushi/extensions/repo/index.min.json. Refresh the Extensions tab after adding it.

Why are extensions not showing after adding the repo?

After adding the Keiyoushi repo, you need to restart Tachiyomi completely and then tap the refresh icon in the Extensions tab. Some devices don’t load the catalog until the app is fully restarted.

Does Keiyoushi work with Mihon?

Yes, Keiyoushi works perfectly with Mihon and all Tachiyomi forks including Aniyomi, TachiyomiJ2K, TachiyomiSY, Komikku, and Yokai. The same repository URL works across all apps.

How do I update installed extensions?

Go to Browse > Extensions in Tachiyomi or Mihon. Extensions with available updates will show an Update button. You can tap Update All or update individual extensions one by one.
