			                if (selectedSuggestionIndex >= 0 && suggestions[selectedSuggestionIndex]) {
			                    suggestions[selectedSuggestionIndex].click();
			                } else {
			                    performSearch();
			                }
			            } else if (e.key === 'Escape') {
			                hideSuggestions();
			                selectedSuggestionIndex = -1;
			            }
			        });
			
			        function updateSelectedSuggestion(suggestions) {
			            suggestions.forEach((item, index) => {
			                item.classList.toggle('selected', index === selectedSuggestionIndex);
			            });
			        }
			
			        // Handle search on icon click
			        if (searchIcon) {
			            searchIcon.addEventListener('click', function() {
			                performSearch();
			            });
			        }
			
			        // Auto-suggest functionality
			        let searchTimeout;
			        const suggestionsContainer = document.querySelector('#search-suggestions');
			
			        searchInput.addEventListener('input', function() {
			            clearTimeout(searchTimeout);
			            const query = this.value.trim();
			
			            if (query.length >= 2) {
			                searchTimeout = setTimeout(() => {
			                    fetchSearchSuggestions(query);
			                }, 300);
			            } else {
			                hideSuggestions();
			            }
			        });
			
			        // Hide suggestions when clicking outside
			        document.addEventListener('click', function(e) {
			            if (!searchInput.contains(e.target) && !suggestionsContainer.contains(e.target)) {
			                hideSuggestions();
			            }
			        });
			
			        // Show suggestions when focusing on input
			        searchInput.addEventListener('focus', function() {
			            const query = this.value.trim();
			            if (query.length >= 2) {
			                fetchSearchSuggestions(query);
			            }
			        });
			    }
			
			    // Search function
			    function performSearch() {
			        const searchInput = document.querySelector('#main-search');
			        if (searchInput) {
			            const query = searchInput.value.trim();
			
			            if (query.length > 0) {
			                hideSuggestions();
			                // Redirect to search results page
			                const searchUrl = 'https://hotphim.org/?s=' + encodeURIComponent(query);
			                window.location.href = searchUrl;
			            }
			        }
			    }
			
			    // Fetch search suggestions
			    function fetchSearchSuggestions(query) {
			        const suggestionsContainer = document.querySelector('#search-suggestions');
			
			        // Show loading state
			        suggestionsContainer.innerHTML = '<div class="suggestion-item loading">Đang tìm kiếm...</div>';
			        suggestionsContainer.style.display = 'block';
			
			        // Make AJAX request to get suggestions
			        const formData = new FormData();
			        formData.append('action', 'search_suggestions');
			        formData.append('query', query);
			        formData.append('nonce', '9c0845c61a');
			
			        fetch('https://hotphim.org/wp-admin/admin-ajax.php', {
			                method: 'POST',
			                body: formData
			            })
			            .then(response => response.json())
			            .then(data => {
			                if (data.success && data.data.length > 0) {
			                    displaySuggestions(data.data);
			                } else {
			                    suggestionsContainer.innerHTML =
			                        '<div class="suggestion-item no-results">Không tìm thấy gợi ý</div>';
			                }
			            })
			            .catch(error => {
			                console.error('Search suggestions error:', error);
			                hideSuggestions();
			            });
			    }
			
			    // Display search suggestions
			    function displaySuggestions(suggestions) {
			        const suggestionsContainer = document.querySelector('#search-suggestions');
			        let html = '';
			
			        // Reset selected index
			        selectedSuggestionIndex = -1;
			
			        suggestions.forEach(suggestion => {
			            const icon = suggestion.type === 'category' ? 'fa-tags' : 'fa-film';
			            html += `<div class="suggestion-item" data-query="${suggestion.title}" data-url="${suggestion.url}">
			                    <i class="fa-solid ${icon}"></i>
			                    <span>${suggestion.title}</span>
			                    ${suggestion.type === 'category' ? '<small class="suggestion-type">Thể loại</small>' : ''}
			                </div>`;
			        });
			
			        suggestionsContainer.innerHTML = html;
			        suggestionsContainer.style.display = 'block';
			
			        // Add click handlers to suggestions
			        const suggestionItems = suggestionsContainer.querySelectorAll('.suggestion-item');
			        suggestionItems.forEach(item => {
			            item.addEventListener('click', function() {
			                const query = this.getAttribute('data-query');
			                const url = this.getAttribute('data-url');
			
			                if (url && url !== 'undefined') {
			                    // Direct navigation to the item
			                    window.location.href = url;
			                } else {
			                    // Perform search with the query
			                    const searchInput = document.querySelector('#main-search');
			                    searchInput.value = query;
			                    performSearch();
			                }
			            });
			        });
			    }
			
			    // Hide suggestions
			    function hideSuggestions() {
			        const suggestionsContainer = document.querySelector('#search-suggestions');
			        suggestionsContainer.style.display = 'none';
			    }
			
			    // js Header scroll effect - add nền background khi scroll
			    const header = document.querySelector('header');
			    let lastScrollTop = 0;
			
			    if (header) {
			        window.addEventListener('scroll', function() {
			            const scrollTop = window.pageYOffset || document.documentElement.scrollTop;
			
			            if (scrollTop > 50) {
			                // Add fixed class when scrolled down
			                header.classList.add('fixed');
			            } else {
			                // Remove fixed class when at top
			                header.classList.remove('fixed');
			            }
			
			            lastScrollTop = scrollTop;
			        }, false);
			    }
			});

// Helper function to parse search query from current URL
function getCurrentSearchQuery() {
    const currentUrl = new URL(window.location);
    if (currentUrl.pathname.includes('/search/')) {
        const pathParts = currentUrl.pathname.split('/search/')[1].split('/');
        const searchQuery = pathParts[0]; // Lấy phần đầu tiên (search query)
        return searchQuery.replace(/-/g, ' '); // Decode the search query
    }
    return '';
}

// Helper function to get current filters from URL
function getCurrentFilters() {
    const currentUrl = new URL(window.location);
    const filters = {};

    const filterKeys = ['type', 'country', 'category', 'year', 'age_rating', 'language', 'sort'];
    filterKeys.forEach(key => {
        if (currentUrl.searchParams.get(key)) {
            filters[key] = currentUrl.searchParams.get(key);
        }
    });

    // Get release year filters
    const releaseYears = currentUrl.searchParams.getAll('release-year[]');
    if (releaseYears.length > 0) {
        filters.release_year = releaseYears;
    }

    return filters;
}

// Function to generate search URL with WordPress standard permalink structure
function getSearchUrl(searchQuery, filters = {}, paged = 1) {
    // Clean search query - convert to slug format
    searchQuery = searchQuery.trim();
    if (!searchQuery) {
        return 'https://hotphim.org/search/';
    }

    // Convert to slug format (replace spaces with hyphens, remove special chars)
    searchQuery = searchQuery.replace(/[^a-zA-Z0-9\s-]/g, '').replace(/\s+/g, '-').toLowerCase();

    // Build base URL with search query - WordPress standard format
    let baseUrl;
    if (paged > 1) {
        baseUrl = 'https://hotphim.org/search/' + searchQuery + '/page/' + paged + '/';
    } else {
        baseUrl = 'https://hotphim.org/search/' + searchQuery + '/';
    }

    // Add filter parameters as query string
    const queryParams = [];

    const filterKeys = ['type', 'country', 'category', 'year', 'age_rating', 'language', 'sort'];

    filterKeys.forEach(key => {
        if (filters[key]) {
            queryParams.push(key + '=' + encodeURIComponent(filters[key]));
        }
    });

    // Add release year filters
    if (filters.release_year && Array.isArray(filters.release_year)) {
        filters.release_year.forEach(year => {
            queryParams.push('release-year[]=' + encodeURIComponent(year));
        });
    }

    // Append query parameters if any
    if (queryParams.length > 0) {
        baseUrl += '?' + queryParams.join('&');
    }

    return baseUrl;
}

            }

            // Show filter for movies
            if (filterToggle) {
                filterToggle.style.display = 'flex';
            }
            if (filterElements) {

        } else if (activeTab === 'casts') {

            if (castsTab) {

            // Hide filter for actors

                filterToggle.style.display = 'none';
            }
            if (filterElements) {
                filterElements.classList.remove('show');
            }
        }

    // Add click event listeners to tabs
    if (moviesTab) {
        moviesTab.addEventListener('click', function(e) {
            e.preventDefault();
            switchTab('movies');

        castsTab.addEventListener('click', function(e) {

        filterToggle.addEventListener('click', function() {
            filterElements.classList.toggle('show');
            filterToggle.classList.toggle('toggled');
        });

    // Đóng panel bộ lọc

            filterElements.classList.remove('show');

            if (selectedReleaseYears.length > 0) {

            // Chuyển hướng với URL mới
            window.location.href = newUrl;

    // Lựa chọn item bộ lọc

    function updateReleaseYearFilterState(container) {

            '.item[data-release-year].active:not([data-release-year="all"])');
        const allOption = container.querySelector('[data-release-year="all"]');

        // Thêm visual indicator cho multi-select

            container.classList.add('multi-selected');
            if (allOption) {
                allOption.classList.add('has-selections');
            }
        } else {
            container.classList.remove('multi-selected');
            if (allOption) {
                allOption.classList.remove('has-selections');
            }
        }
    }

    // Khởi tạo trạng thái visual cho bộ lọc năm sản xuất khi load trang
    const releaseYearContainer = document.querySelector('.release-year-filter');
    if (releaseYearContainer) {
        updateReleaseYearFilterState(releaseYearContainer);
    }

    // PAGINATION HANDLING - Support both movies and actors pagination
    function setupPaginationHandling(containerId) {
        const paginationContainer = document.getElementById(containerId);
        if (paginationContainer) {
            const pageInput = paginationContainer.querySelector('.page-current input[type="number"]');
            const prevBtn = paginationContainer.querySelector('[data-page-btn="prev"]');
            const nextBtn = paginationContainer.querySelector('[data-page-btn="next"]');

            // Navigate to specific page
            function navigateToPage(page) {
                const pageNum = parseInt(page);
                if (pageNum >= 1) {
                    // Get current search query and filters from URL using helper functions
                    const searchQuery = getCurrentSearchQuery();
                    const filters = getCurrentFilters();

                    // Generate new URL with page number using WordPress standard format
                    const newUrl = getSearchUrl(searchQuery, filters, pageNum);
                    window.location.href = newUrl;
                }
            }

            // Handle Previous button
            if (prevBtn) {
                prevBtn.addEventListener('click', function(e) {
                    e.preventDefault();
                    const currentPage = parseInt(pageInput.value) || 1;
                    if (currentPage > 1) {
                        navigateToPage(currentPage - 1);
                    }
                });
            }

            // Handle Next button
            if (nextBtn) {
                nextBtn.addEventListener('click', function(e) {
                    e.preventDefault();
                    const currentPage = parseInt(pageInput.value) || 1;
                    const totalPages = parseInt(pageInput.getAttribute('max')) || 1;
                    if (currentPage < totalPages) {
                        navigateToPage(currentPage + 1);
                    }
                });
            }

            // Handle page input
            if (pageInput) {
                pageInput.addEventListener('keydown', function(e) {
                    if (e.key === 'Enter') {
                        const page = parseInt(this.value);
                        const totalPages = parseInt(this.getAttribute('max')) || 1;
                        if (isNaN(page) || page < 1) {
                            this.value = 1;
                            navigateToPage(1);
                        } else if (page > totalPages) {
                            this.value = totalPages;
                            navigateToPage(totalPages);
                        } else {
                            navigateToPage(page);
                        }
                    }
                });
            }
        }
    }

    // Setup pagination for both movies and actors
    setupPaginationHandling('movies-pagination');
    setupPaginationHandling('actors-pagination');
});
