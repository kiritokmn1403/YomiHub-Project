🔎 Verify your download

The hashes below are for version 0.6.3. Use the SHA-256 list for the same release as the file you downloaded.

  • SHA-256 checksums 1.6 KB
    Find the checksum next to the exact filename.
    a486112a31e0df92…
  • Changelog 23.7 KB
    Read the changes in version 0.6.3.
    1e94562729cc473d…

On Windows, open PowerShell in your downloads folder. Replace the filename in this command with the name of the file you want to verify.

Get-FileHash -Algorithm SHA256 -LiteralPath ".\YomiHub-0.6.3-windows-x64-Setup.exe"

In Command Prompt, you can use certutil -hashfile "YomiHub-0.6.3-windows-x64-Setup.exe" SHA256.

On Android, open the APK in a file manager that can calculate hashes and select SHA-256.

Compare all 64 characters with the entry for the exact filename in the SHA-256 list. Uppercase and lowercase letters are equivalent. If the hashes differ, download the file again from the release and verify it before opening it.
