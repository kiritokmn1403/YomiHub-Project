      📦 Choose and install YomiHub

      Choose the package for your device and operating system. If you are updating, make a backup before installing the new version over the old one.

      Phones, tablets and TVs

      1. Check which version of Android your device runs. For Android 7 or later, choose a standard APK. If you are unsure which processor architecture to select, try arm64-v8a. Android 6.0 devices use the package marked android6. For TVs, use YumiHub Android TV.
      2. Open the downloaded APK. If Android prompts you, allow the app that opened the file to install apps from this source, then return to the APK to continue.
      3. To keep your data when updating, install the same package variant over your current version. If your device cannot install the update, keep your current version until you have backed up your data.

      Windows 10 or 11 (x64)

      • Run Setup.exe to install YomiHub. For the portable .zip version, extract the archive and run the app from the extracted folder.
      • If you use APK extensions, choose -full.zip. It includes Java and M-Extension-Server to run them.
      • If you choose .appxbundle, also download YomiHub-RootCA.cer, Install-YomiHub.bat and Install-YomiHub.ps1 from the same release. Put all four files in one folder, then run the .bat file.

      🧭 Find your way around the app

      Open Library to return to your saved titles. In layouts with an Activity tab, you can switch between Updates and History.

      MoreSettingsAppearanceApp interface

      • Choose a layout: YomiHub Old Version, Shiori (0.9.95) or YomiHub New Version. Each layout may group items differently.
      • Open Browse to find sources. Once the corresponding features are enabled, Booru opens the image collection and Bookshelf opens your collection of physical books.

      MoreSettingsFeatures & extension sources on/offCustomize navigation bar order

      • Here you can reorder navigation items and choose which ones to show or hide.

      🧩 Add a repository and install extensions

      A repository is a list of extensions. After adding one, install an extension from it to make its source available in the app.

      MoreSettingsBrowseExtensions Repo

      1. Select Add if you have the repository address, or open Suggested repos to choose one from the list.
      2. Return to Browse, open Extensions, find the extension in the repository you just added and install it.
      • If you have a repository QR code, open QR code in settings, scan the code or select its image, then choose Add extension repo.
      • Repositories offer extensions for comics, video or novels. Examples include Mangayomi extensions, LNReader plugins, Aniyomi APK extensions and Kotatsu parsers.
      • If a source moves to a new domain, use Change URL in the extension settings. If the extension still sends requests to the old domain, Force URL change also redirects matching requests to the new one.

      📖 Find something to read or watch

      Each extension has its own catalogue. Open a title to choose a chapter to read or an episode to watch.

      BrowseSources

      1. Choose an installed source. Browse Popular or Latest, or open Filter to narrow the results.
      2. Open a title. On its details page, add it to your library to find it again. For comics and novels, you can download chapters to read later or open the original page in WebView.
      3. Select a chapter to read a comic page by page or read the text of a novel. For video, select an episode to open the player.
      • If an episode is available from multiple servers, you can switch servers in the player. When you reopen an episode, playback can resume from your saved position.
      • On supported devices, picture-in-picture (PiP) keeps the video in a small window. To watch vertical videos, turn on Short Video for every video extension in the feature settings.

      🔎 Filter titles by genre

      The new filter layout arranges source options into nine main groups, including genre and release year. Additional options may appear under Other.

      BrowseSources

      1. Open a source and select Filter. If options are missing, select Load Filters to fetch the list from the source again.
      2. Open Genres and choose the genres to filter by. Tap a three-state checkbox once to include a genre, again to exclude it and a third time to clear the condition.
      3. Select Filter to apply your choices. Use Bookmark to save them or Reset to start again.

      MoreSettingsAppearanceFilter layout

      • Choose Old filter to use the previous layout.

      🔗 Merge titles and extensions

      If several sources carry a title, merging their entries lets you switch sources from the chapter list. You can also group extensions yourself.

      MoreMerge extensionsMerge content

      1. Choose Scan for duplicate names and suggest merging to see possible matches, or select Choose titles to merge.
      2. Check the titles and sources before confirming. If you merge the wrong entries, reopen the group and undo the merge.
      • To group extensions, return to Merge extensions, select Choose extensions to merge, choose the sources and then select the destination extension.
      • When the details page shows Merged · N sources, N is the number of sources in the group. Use Read from an extension in the merged set to choose which source supplies the chapter list.

      📚 Manage your physical book collection

      Track the volumes you own, those you are missing and those you have lent out. If the bookshelf is not visible, enable it in settings.

      BookshelfAdd new series

      1. Enter a series name, save it and open the series you just created.
      2. Tap a volume number to mark it as owned. Tap again to clear the mark. Press and hold to add a note, enter a price, update reading progress or record a loan. Use Bulk select to work with several volumes at once.
      • Use Scan barcode to read an ISBN. In Quick Search, you can enter a title without accents. Open To Buy for your shopping list, Limited Edition for special editions or Statistics for collection totals.
      • Under Options, choose Export CSV to get a template or Import CSV to add records. Keep the nine column headings in this order: Tên bộ,Tập,Phiên bản,ISBN,Giá,Ngày mua,Nơi mua,NXB,Trạng thái đọc (series, volume, edition, ISBN, price, purchase date, place of purchase, publisher, reading status).
      • Turn on Back up Personal Bookshelf data when creating a backup to transfer your collection to another device.
      Personal Bookshelf is unavailable on Android TV.

      🖼️ Find and save Booru images

      Search by tag on the Booru site of your choice. You can save favorite images and reuse earlier searches.

      BooruBooru App settingsAdd Booru site

      1. Add the site you want to use, return to Booru and open Choose Booru site to switch to it.
      2. In Browse, enter a tag such as scenery and search. Open an image and tap the heart to save it to Favorite.
      • Open Search history to repeat a search. When making a backup, turn on Back up Booru App data to include your Booru data.

      📘 Use Google Play Books

      YomiHub opens Google Play Books inside the app. In layouts that group libraries together, follow this path to find your books.

      LibraryPlay Books

      1. Open Play Books. When prompted by Google, sign in with the Google account you use for your books.
      2. Enter a title in Search on Play Books, then select a result.
      Google Play Books is unavailable on Android TV.

      📖 Open ebooks and PDFs on your device

      You can open books stored on your device without adding them to your library.

      MoreEbook & PDF

      1. Choose Open Ebook for an EPUB or Open PDF file for a PDF.
      2. In the file picker, find the folder containing the book and select the file to read it.

      🌐 Choose a connection for extensions and the browser

      Choose a network service and which parts of YomiHub use it.

      MoreVPN & DNSVPN service

      1. To use Tor, select Enable Tor. Only one VPN service can be active at a time.
      2. On Android, under Bridges (when the network blocks Tor), select Automatic to try a direct connection before trying a bridge.
      3. Enable Switch to Tor automatically when a site is blocked to let extensions retry through Tor after certain network errors. This includes extensions outside your selected VPN scope.
      • Under VPN for extensions, WebView & browser, select the extensions that should use the VPN. The extension WebView and the in-app browser have separate switches.
      • On Android, the selected scope applies to Tor, Mihon Proxy and custom proxies. WARP, OpenVPN, WireGuard and SoftEther route all YomiHub traffic through the VPN. On Windows, the scope also applies to WARP and WireGuard. OpenVPN and SoftEther apply to the entire computer. After changing the scope, restart YomiHub for WebView2 on Windows to use the new settings.
      • Open Target country if your service lets you choose a country. Open DNS to configure DNS-over-HTTPS and choose a DNS provider.
      • In Settings, open Ad blocking (AdBlock) to adjust ad filters or Cloudflare Bypass Setting to see verification options.

      🧭 Browse the web, download media and check a page

      Savior lists media files detected on a page. Web Scanner checks the web address for signs of security problems.

      MoreBrowser

      1. Open a page containing the video or audio you want to save, then select Savior – download media on the page.
      2. If the list is empty, select Scan page source for video links. If it finds new links, reopen Savior.
      3. Select the download button beside the file, if available. If a stream offers several quality levels, choose the one you want to download.
      • To check HTTPS, redirects or signs of malware, open the browser menu and select Web Scanner – check this page.

      💾 Back up and transfer data to another device

      Use a backup to transfer your library or restore saved items when switching devices.

      MoreBackup & Sync

      1. To bring your favorite images, Booru history or book collection with you, enable Back up Booru App data, Back up Personal Bookshelf data or both, depending on what you want to keep.
      2. Select Create backup, choose the items to include and save the file.
      3. On the receiving device, open the same menu, select Restore backup and choose the transferred file.
      • For scheduled backups, set the frequency, number of copies to keep and save location. You can also adjust compression or enable encryption. If you encrypt your backups, keep the details needed to unlock them.
      • Select Back Up to Google Drive to sign in with Google and save a backup to Drive. Under Cloud backup, you will also find Google Drive – Client ID, OneDrive, Dropbox, WebDAV, Rclone, MediaFire and Telegram (bot).
      • Use Send to another app to transfer a backup through a sharing app on your device.

      🧰 Share files, track progress and use other tools

      Choose a tool for the task at hand, from sending a file to a nearby device to setting a reminder to rest your eyes.

      MoreSettings

      • Use AirDrop & Quicksharing to send or receive files between supported devices. You can also open it directly from More.
      • Open Tracking to choose a service such as AniList or MyAnimeList to track what you read or watch.
      • Under Health Connect & Health, set reminders to rest your eyes using the 20-20-20 rule.
      • Open GIF Viewer to view animations frame by frame, SpeedTest to test your connection or QR code to scan a code with your camera or from a saved image.
      • Under More, select Statistics to see usage figures, Calendar to view the calendar or Categories to manage how your content is grouped.

      📝 Check your version and report a bug

      The About screen shows your app version and provides logs that can help you describe a problem.

      MoreAbout

      1. Note the number under Version. Turn on Enable logging, then repeat the action that caused the problem.
      2. Open App log. Search for a keyword or enable Errors only to narrow the results.
      3. Return to About and select Share app logs. When reporting the bug on GitHub Issues, attach the relevant log entries along with the app version and the steps you took.
      • Select Check for update to check now. Enable Check for app updates on startup to check automatically.
      • Error reports opens the list of recorded reports. GitHub projects used lists the projects used by YomiHub.

      📺 Use YomiHub on Android TV and Windows

      On TV, use the remote to navigate. On Windows, the diagnostics screen helps you identify missing components.

      MoreSettingsWindows diagnostics

      • On Android TV, use the directional pad to move the focus and press the center button to select. The TV version focuses on films and video. Comics, novels, Google Play Books, Booru and Personal Bookshelf are unavailable.
      • On Windows, if you use the portable version and need APK extensions, choose -full.zip, which includes Java and M-Extension-Server. The diagnostics screen shows which components are missing.
      • On Windows, the log is usually at Documents\YomiHub\logs.txt. You can also open it from About.

      ❓ Frequently asked questions

      Find the question that matches what you are trying to do.

      What if an extension’s page will not load?

      If the site has moved, open Change URL on the extension page and enter its new address. If you suspect your network is blocking the site, open VPN & DNS, enable Tor and Switch to Tor automatically when a site is blocked, wait for Tor to connect and try again.

      What if a page asks for Cloudflare verification?

      Open the page in the extension’s WebView and complete the verification shown on screen. If it keeps appearing, check whether the WebView and extension are using the same network connection.

      Why can’t I select a genre?

      In the new filter layout, tap Load Filters to fetch the options from the source again. If the list stays empty, check your connection and look for an extension update.

      Will I lose my data when I update?

      Make a backup first. Install the new version of the same app variant over your existing installation to keep your data. Avoid uninstalling the old version or clearing app data before the update.

      How do I move my library to another device?

      Make a backup, choose what to transfer and send the file to the other device. On that device, select Restore backup and open the backup file.

      What should I include in a bug report?

      Describe what you expected, what happened and how to reproduce it. Use Share app logs on the About screen to get the log to attach.

      • Include the extension name, app version and the last action you took before the problem occurred.
